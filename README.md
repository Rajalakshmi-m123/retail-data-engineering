# retail-data-engineering & Analytics Project
Retail Data Engineering Use Case — NeoStat Assessment

## Overview

This project was completed as part of the NeoStat Retail Data Engineering Use Case Assessment.

The objective was to:

- Clean and validate retail transaction data
- Create a curated dataset for analytics
- Build an interactive Power BI dashboard
- Generate business insights from sales performance

---

## Tech Stack

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Power BI

---

## Project Structure

### Code
Contains data cleaning, transformation and validation notebooks.

### Dataset
Contains raw and curated retail datasets.

### Power BI
Contains the interactive dashboard (.pbix).

### Documentation
Contains assessment documents and supporting materials.

## Key Findings

- Electronics contributes the highest revenue.
- Laptop is the top-performing product.
- Chennai generates the highest city-level revenue.
- Online and offline sales contribute almost equally.
- Revenue is concentrated within a small number of products.
